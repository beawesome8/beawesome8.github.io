# beawesome8.github.io

Source for my personal portfolio site, served via GitHub Pages at [beawesome8.github.io](https://beawesome8.github.io).

## Stack

Plain HTML, CSS, and JavaScript — no build step, no framework.

- `index.html` — page content
- `style.css` — styling
- `script.js` — interactive bits (nav, skill filters, terminal, scroll reveals)

## Running locally

Open `index.html` directly in a browser, or serve the folder with any static file server, e.g.:

```
npx serve .
```
